# Test photos (kept off GitHub)

Put one folder per person here. Photos in this folder are ignored by Git, and the
scripts only read them. They never copy or save images.

```
test_photos/
  aravind/   1.jpg 2.jpg 3.jpg 4.jpg 5.jpg
  friend1/   1.jpg 2.jpg 3.jpg
  friend2/   1.jpg 2.jpg 3.jpg
```

Tips for a fair test:
- 4 to 6 photos of yourself, 2 to 3 each of at least 2 other people.
- Mix conditions: indoor and outdoor light, with and without glasses, slight left and right turns.
- One clear face per photo works best. If a photo has several faces, the biggest one is used.
